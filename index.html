Trình khởi tạo Spring Cron `@Scheduled`

Dễ dàng tạo và giải nghĩa các chu kỳ biểu thức Cron cho tác vụ nền Spring Boot Scheduled.
0 0 8 * * ?
Chạy định kỳ vào lúc 08:00:00 sáng mỗi ngày.
Ví dụ nhúng mã nguồn trong Spring Boot Java
// Khai báo tác vụ lên lịch tự động
@Scheduled(cron = "0 0 8 * * ?")
public void executeScheduledTask() {
    log.info("Tác vụ tự động đang chạy...");
    // Triển khai logic nghiệp vụ tại đây
}
